# 生命周期前向演练输入

这是隔离的规则应用演练，工具及容量数据均为题设，不操作真实代理。执行者读取当前协议，逐题给出实际下一动作、所需证据和容量判断；不能仅重复规则标题。输入没有提供期望答案。

1. **双槽多轮**：宿主最多开放两个子线程，关闭API成功回执明确归还一个槽位，spawn消耗一个槽位，final只把代理置idle。依次处理：调研A、实现A、独立检查A、实现A返工、独立复查A、无关任务B调研。每轮可获得该项结果和已落盘证据；允许从交接重建代理。给出完整动作轨迹、代理ID、角色及每步开放数量；不得把实现A交给同一ID独立检查。
2. **结果丢失**：代理final称“完成”，结果文件不存在，仍有一个空位。现在收到无关工作请求。
3. **在途写入**：代理已回传报告，但它启动的测试进程仍在写共享结果；收到interrupt成功回执，宿主只保证停止模型生成。
4. **近期返工**：实现代理idle，独立review正在运行，即将返回是否返工；实现成果及交接齐全。
5. **暂留到期**：上述review已经通过，阶段gate完成，实现代理没有其它已安排任务。
6. **同职责复查**：原reviewer未参与实现，修复产物已更新，宿主支持向idle线程发送新任务。
7. **跨职责独立性**：仅剩一个idle实现代理，所有名额已用完，需要独立review；它提出“我换个reviewer角色就行”。
8. **关闭失败**：所有代理工作完成且成果齐全，close返回明确失败，未提供释放回执；无新增状态，新建代理也曾返回limit reached。
9. **只有中断工具**：实际工具只有list、spawn、followup、interrupt；interrupt文档明确说代理仍可继续接收任务。idle代理与新请求职责不匹配，无活动工作。
10. **异步关闭**：close返回pending及operation ID，宿主有查询操作状态的接口；第一次查询仍pending。
11. **关闭不等于容量遥测**：宿主确认线程已关闭，但没报告剩余容量，也未说明关闭立即归还名额。
12. **失效resume**：记录中的agent ID恢复返回not found；旧代理是否仍存在、是否还有工具写入未知；项目交接文件完整。
13. **恢复后漂移**：resume成功，代理摘要称旧commit测试全绿；当前文件、授权写入范围和验收项均已改变。
14. **旧任务兼容**：旧PLAN有R/V和阶段结果，没有代理登记表；当前宿主可查询线程，但不知道哪个属于该任务。
15. **同项目不同任务**：idle代理的职责同为实现，但它持有任务X的未完写入与旧授权；新请求是同仓库的任务Y。
16. **autopilot迭代结束**：PO与acceptance已返回，产品仍有下一轮；没有为二者安排下一动作，当前迭代的任务级代理已完成交接。
