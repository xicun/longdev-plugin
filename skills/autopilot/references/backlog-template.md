## 规则

- 状态：⬜ 候选 / ▶ 本轮 / ✅ 已交付 / 🚫 隔离 / 💤 推迟 / ➖ 已删减。
- **「宪章依据」引不出条款编号的不入表**——这是防功能爆炸的主闸，比任何措辞约束都硬。「用户应该会喜欢」不是依据，是发散的开端。
- 分 1–5：对宪章核心场景的贡献度。低于宪章 B2 阈值的不选入 ▶；某轮全部候选低于阈值 → 报收官，不硬凑。
- **减法项**（删掉/简化已有功能）与加法同权入表、同规则评分——只会做加法的循环天然膨胀。
- 每轮 ▶ 数量 ≤ 宪章 B1 的每轮上限。
- 🚫 必须带 `iterations/<N>.md` 指针；🚫 永不静默重试，解禁唯一途径是用户修宪时点名。
- 「观察」区只搬运 acceptance 报告的观察节原文，不评分、不改写成功能句式。
